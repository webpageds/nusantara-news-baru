EDITOR NASKAH

Tulis berita baru

Isi berita

Gunakan huruf kecil, angka, dan tanda hubung. Slug tidak boleh sama dengan artikel lain.
Versi awal menyimpan teks biasa. Paragraf akan ditampilkan sesuai pemisah baris.
Isi sumber untuk menjaga atribusi dan memudahkan verifikasi redaksi.

AKSES INTERNAL

Tim redaksi

Kelola peran melalui database Supabase. Pendaftaran akun publik sengaja dimatikan.

Untuk menambah anggota, undang email melalui Supabase Dashboard → Authentication → Users. Setelah akun dibuat, tambahkan baris profil di tabel profiles dan tetapkan peran admin atau editor. Admin tidak dapat diberikan lewat formulir publik.
